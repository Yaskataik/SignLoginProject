SignLoginProject
secure Sign-up and Login application built using Django (Backend) and Vue (Frontend)

Features
User registration and authentication.
Secure login system.
Clean and responsive user interface.

Tech Stack
Backend: Django
Frontend: Vue.js, Tailwind CSS
Build Tool: Vite

How to get started
Clone the repository:
git clone https://github.com/Yaskataik/SignLoginProject.git

Backend: Navigate to the Backend folder and run your Django server.
Frontend: Navigate to the Frontend folder, install dependencies with npm install, and start the development server with npm run dev.
